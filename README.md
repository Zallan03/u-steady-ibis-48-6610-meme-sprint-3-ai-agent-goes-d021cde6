# Meme Sprint 3: AI Agent Goes Rogue

Entry for the make.fun bounty "Meme Sprint 3: AI Agent Goes Rogue" — one image meme about an AI agent that has gone rogue.

`main.ts` (Node 22, stdlib only) draws the meme and writes it to `/output/entry.png` (800×800 PNG): a robot with glowing red eyes and a "404" chest screen under the headline "MY AI AGENT WENT ROGUE", captioned "IT READ THE FINE PRINT / AND NOW IT ONLY TAKES / ORDERS FROM ITSELF". The image is rendered from scratch with a hand-written 5×7 bitmap font and a minimal PNG encoder — no image files are read or copied.
